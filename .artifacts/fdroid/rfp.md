## Description

Maxfield Link Overlay is an offline Android floating-window assistant for carrying out portal-link plans generated by Maxfield. It imports Maxfield TXT or CSV assignment files from local storage and displays the current origin portal, destination portal, assigned agent, and progress over the game. It does not request Internet access, read a game account, or automate gameplay.

## Build
