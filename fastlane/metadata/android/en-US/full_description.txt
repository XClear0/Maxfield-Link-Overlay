Maxfield Link Overlay helps agents carry out portal-link plans generated by Maxfield while keeping the current instruction visible over the game.

Import an agent_assignments.txt, agent_N_assignment.txt, or agent_assignments.csv file from local storage. The translucent floating window shows the current link's origin portal, destination portal, assigned agent, and overall progress. Previous and next buttons let you move through the plan without returning to the main app.

Features:
* Supports Maxfield TXT and CSV assignment files
* Shows the current origin and destination portal over other apps
* Changes the whole overlay color when the origin changes from the previous link
* Moves to the previous or next link with large floating controls
* Remembers the current link and overlay position
* Provides a persistent notification with a stop action
* Works entirely offline and does not request Internet access

The app does not read a game account, automate gameplay, or upload imported plans. Imported data remains in the app's local storage.
